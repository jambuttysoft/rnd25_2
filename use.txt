Experiment 1 — Equipment Verification
Что загружать, чтобы получить удачный результат:
Поле	Удачный материал
Equipment Photo	Чёткое фото IT-оборудования спереди: сервер Dell/HPE/Lenovo, коммутатор Cisco, маршрутизатор, ИБП. Видны логотип, порты, индикаторы. Хорошее освещение, без сильных бликов.
Receipt	Реальный инвойс/чек на то же оборудование: та же модель, бренд, сумма в рыночном диапазоне, тот же vendor.
Form fields	Можно оставить пустыми, если загружен чек — OCR подхватит данные. Если чека нет, вручную ввести корректные данные.
Ожидаемый результат: VERIFIED, APPROVE, high confidence.
Что загружать, чтобы получить обратный (неудачный) результат:
Поле	Неудачный материал
Equipment Photo	Фото не-IT: кошка, машина, строительный инструмент, пустая стойка.
Receipt	Чек на совершенно другое: ремонт ванной, продукты, бензин. Или чек на сервер Dell, но фото — коммутатор Cisco.
Form fields	Намеренно ложные: vendor = «FakeCorp», amount = $1, item = «pizza».
Ожидаемый результат: NOT_VERIFIED / MISMATCH, REJECT, discrepancies по бренду/цене/категории.
Experiment 2 — Hidden Asset Detection
Что загружать, чтобы получить удачный результат:
Поле	Удачный материал
Equipment Photo	Профессиональный инструмент или IT-железо, которое в ERP числится как «Consumables»: дрель Hilti, мультиметр Fluke, сервер Dell в коробке, аккумуляторный инструмент DeWalt/Makita, промышленный ноутбук Panasonic Toughbook.
ERP Category	Consumables, Materials, Office Supplies, Misc — то есть категория, в которой такое оборудование не должно быть.
Ожидаемый результат: capital_equipment_found >= 1, recoverable_value = high/medium, recommendation по переклассификации.
Что загружать, чтобы получить обратный результат:
Поле	Неудачный материал
Equipment Photo	Настоящие расходники: моток кабеля, стяжки, скотч, клеевые стержни, упаковка винтов, одноразовые перчатки.
ERP Category	Consumables — система подтвердит, что классификация верна.
Ожидаемый результат: capital_equipment_found = 0, recoverable_value = low, нет активов для восстановления.
Experiment 3 — Infrastructure Integrity
Что загружать, чтобы получить удачный результат:
Поле	Удачный материал
Infrastructure Photo	Фото работающего коммутатора/сервера: воткнуты patch-кабели, горят зелёные/янтарные LED, подключены power-кабели к БП, кабель-менеджмент заполнен.
Node Label	rack-01-switch-a, core-router-03 — любой понятный идентификатор.
Ожидаемый результат: FULLY_INTEGRATED или PARTIALLY_INTEGRATED, integration_score 3–4/4.
Что загружать, чтобы получить обратный результат:
Поле	Неудачный материал
Infrastructure Photo	Фото «мертвого» оборудования: switch в стойке, но без кабелей, все LED выключены, пустой кабель-менеджмент. Или фото задней панели без power cords.
Ожидаемый результат: NOT_INTEGRATED, integration_score 0–1/4 — red flag для fraud-приёмки.
Experiment 4 — Scalability & Optimization
Что «загружать»:
Эксперимент не требует картинок. Только параметры:
Поле	Удачное значение
Image Count	10000 (или больше — нагляднее экономия)
Mode	both — чтобы увидеть side-by-side сравнение baseline vs optimized
Ожидаемый результат: cost_reduction: 65%, speedup: ~25x, cost_per_image: $0.042.
Неудачный вариант:
Поле	Неудачное значение
Image Count	0 или отрицательное — формула отработает, но метрики будут нулевыми/бессмысленными.
Mode	optimized без baseline — не будет comparison, только одна колонка.
Общие технические требования ко всем фото
- Формат: JPEG, PNG, WebP
- Размер: до 20 MB
- Качество: чёткий фокус, хорошее освещение, минимум бликов
- Рекомендуемое разрешение: 1280×960 и выше
- Не рекомендуется: сильно сжатые/артефактные изображения, скриншоты с фильтрами, фото под углом 90°
Готовые комбинации для проверки
Успешный сценарий «всё совпадает»:
- Exp1: eq.webp (Dell сервер) + invoice.jpg с заменой на IT-инвойс → VERIFIED
- Exp2: фото профессионального инструмента + ERP Consumables → assets recovered
- Exp3: фото живого коммутатора с кабелями → FULLY_INTEGRATED
- Exp4: image_count=10000, mode=both → 65% savings
Провальный сценарий «всё не так»:
- Exp1: eq.webp (Dell сервер) + invoice.jpg (плитка) → NOT_VERIFIED / REJECT
- Exp2: фото кабелей и стяжек + ERP Consumables → 0 capital assets
- Exp3: фото сервера без кабелей → NOT_INTEGRATED
- Exp4: image_count=0 → нулевые метрики
